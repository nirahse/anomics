# Nira's EVE Online Burner & Anomic Mission Guides 🚀

### 🇩🇪 Für die deutsche EVE Online Community

## 🌎 Project Overview (English for Search Engine Optimization)

**Nira's Anomics Guides** is a dynamic web application built for EVE Online players looking for specialized Level 4 Anomic (Burner) Mission Guides. 

This repository contains the source code for the Streamlit application, serving optimized ship configurations (fittings), tracking strategies, and damage profiles.

## 🌟 Key Features

*   **Interactive Fittings:** Explore and filter optimized ship configurations (Pyfa/in-game export compatible) for every Burner type.
*   **Tactical Walkthroughs:** Detailed guides on navigation, positioning, tracking, damage profiles.
*   **Multi-Language Support:** Designed for the German EVE Online community.
*   **Dynamic UI:** Built with Python and Streamlit for a fast, responsive, and clean user experience.

## 🗺️ Covered Burner Missions & Guides

The application provides specialized strategies and fittings for:

*   **Anomic Agent Missions:** (Burner Fregatten) – *Daredevil, Dramiel, Cruor, Succubus, Worm*
*   **Anomic Team Missions:** (Burner Teams) – *Hawk, Vengeance, Harpy, Enyo (including Logistics Support)*
*   **Anomic Base Missions:** (Burner Basen) – *Talos, Ashimmu*

## ⚙️ Tech Stack & Setup

This application is written in **Python** and deployed via the **Streamlit Community Cloud**.

### Local Installation & Development

If you want to run this application locally or contribute to the project, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/nirahse/anomics
    cd YOUR-REPO-NAME
    ```

2.  **Install dependencies:**
    Make sure you have Python 3.8+ installed. Then run:
    ```bash
    pip install -r requirements.txt
    ```
    
3.  **Run the Streamlit App:**
    ```bash
    streamlit run app.py
    ```
